# CampusSpace — система бронирования учебных пространств

Учебный проект: веб-сервис для поиска и бронирования аудиторий, переговорных, коворкингов и компьютерных классов университета.

## Возможности

- Каталог помещений с фото, вместимостью, оснащением и условиями доступа
- Фильтры по названию, вместимости, типу, корпусу и оснащению
- Календарь слотов по 30 минут, бронирование от получаса до целого дня
- Автоматическое подтверждение для обычных помещений, согласование администратором для специализированных
- Личный кабинет: активные брони, история, отмена, повторяющиеся брони
- Отзывы и рейтинги помещений (чистота, оснащение, комфорт)
- Уведомления о статусе заявок и напоминания о ближайших бронированиях
- Регистрация и вход, роли: студент, преподаватель, администратор

## Технологии

- Бэкенд: Python, FastAPI, SQLAlchemy, SQLite
- Фронтенд: HTML, JavaScript, Bootstrap 5
- Документация API: Swagger (автоматически, `/docs`)

## Запуск

```bash
cd backend
python -m venv venv
source venv/Scripts/activate    # Windows PowerShell: venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.seed              # создать базу с тестовыми данными
uvicorn app.main:app --reload
```

Сайт: http://127.0.0.1:8000/
Документация API (Swagger): http://127.0.0.1:8000/docs

## Ключевой сценарий

Список помещений → фильтр по оснащению и вместимости → календарь слотов → бронирование → подтверждение → личный кабинет с активными бронями.

## Структура проекта

```
backend/    FastAPI: модели, схемы, API, тестовые данные
frontend/   страницы и скрипты (Bootstrap)
docs/       ER-диаграмма и SQL-схема
```

## Ограничения прототипа

- SQLite вместо серверной СУБД
- Часть эндпоинтов принимает `user_id` в запросе без сверки с токеном
- Уведомления хранятся в базе и показываются в личном кабинете, без email и push
